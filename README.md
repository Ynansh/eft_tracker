# EFT Tracker

Локальный трекер квестов Escape from Tarkov на русском: отметки выполнения, цепочка Каппы, сюжетные главы, предметы для квестов и убежища. Без входа и сервера — обычные HTML-страницы, прогресс хранится в браузере.

## Запуск

Открыть папку в VS Code и запустить `index.html` через Live Server. Или из терминала:

```bash
python3 -m http.server 5500
```

и открыть http://localhost:5500.

## Что есть

- **Квесты** (`index.html`) — вкладки торговцев, поиск, группы «Доступные» / «Заблокированные», полоска выполненных.
- **Режимы** PvP, PvE и Сезон (KORD BREACH) с отдельным прогрессом; фракции USEC/BEAR.
- **Блокировки** по уровню, лояльности торговцев, репутации Скупщика, сюжету («Тур» открывает торговцев) и предыдущим квестам (цепочка Каппы и сезонная цепочка).
- **Каппа** — список tarkov-market и все квесты, которые к нему ведут.
- **Сюжет** — 10 глав с шагами (`story.html`).
- **Страница квеста** (`quest.html`) — цели, предметы, ключи, прохождение карточками со скриншотами.
- **Предметы** (`items.html`) — для квестов и убежища, отметка «найдено в рейде», счётчики.
- **Сброс** прогресса по разделам.

## Обновление данных

```bash
python3 update_quests.py
```

Скачивает свежие данные tarkov.dev и пересобирает `quests.js`, `items.js`, `story.js`, `guides.js`. Прохождения, сюжет, сезонные квесты и скриншоты с вики (`wiki_*.json`, `img/wiki/`) собираются вручную через браузер: вики закрыта проверкой Cloudflare.

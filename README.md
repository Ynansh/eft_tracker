# EFT Tracker

Локальный трекер квестов Escape from Tarkov: отметки выполнения, цепочка Каппы, сюжетные главы, предметы для квестов и убежища. Без входа и сервера — обычные HTML-страницы, прогресс хранится в браузере.

## Быстрый старт (архив из релиза)

1. Скачать архив со страницы [Releases](https://github.com/Ynansh/eft_tracker/releases/latest):
   - `eft-tracker-full-….zip` (≈ 530 МБ) — со скриншотами прохождений (вики и tarkov.help);
   - `eft-tracker-lite-….zip` (≈ 30 МБ) — то же без скриншотов (скриншоты tarkov.help подгрузятся с их сайта).
2. Распаковать и открыть `index.html` двойным кликом (лучше в Chrome или Edge). Python и интернет не нужны.
3. Только для lite: скриншоты можно докачать позже (около 70 МБ) — нужен [Python](#python), команда в таблице [«Команды»](#команды) — «Докачать скриншоты». После этого обновить страницу.

Прогресс хранится в браузере. Если открывать сайт то из файла, то через Live Server, отметки у них будут разные — лучше пользоваться одним способом.

**Копия прогресса.** В меню слева, в блоке «Прогресс», есть кнопка «Сохранить в файл»: она скачивает `eft-tracker-progress-<дата>.json` со всеми отметками (квесты, сюжет, предметы, убежище, профиль, настройки). Положи файл куда удобно, например в папку трекера. После очистки браузера, его переустановки или на другом компьютере нажми «Загрузить из файла» — отметки вернутся. Сохраняй копию время от времени: браузер сам в файл не пишет.

## Запуск из исходников (git clone или «Download ZIP»)

В репозитории нет собранных данных, иконок и фото квестов — их скачивает скрипт.

1. Установить [Python](#python).
2. Открыть [терминал в папке проекта](#как-открыть-терминал-в-папке-трекера) и один раз выполнить «Скачать или обновить данные» из таблицы [«Команды»](#команды) (около 30 МБ).
3. Открыть `index.html` двойным кликом или через Live Server в VS Code.

## Что где лежит

```
eft-tracker/
├─ index.html      — квесты (открывать этот файл)
├─ items.html      — предметы для квестов и убежища
├─ quest.html      — страница одного квеста
├─ story.html      — глава сюжета
├─ css/            — оформление
├─ js/             — логика страниц
├─ data/           — данные для страниц (создаёт scripts/update_quests.py)
├─ sources/        — данные, собранные вручную: связи, Каппа, прохождения
├─ scripts/        — Python-скрипты: обновление данных, скриншоты, релизы
└─ img/
   ├─ quests/      — картинки квестов (скачивает update_quests.py)
   ├─ items/       — иконки предметов (скачивает update_quests.py)
   ├─ wiki/        — скриншоты с вики
   └─ th/          — скриншоты с tarkov.help
```

## Python

| Как получен трекер | Нужен ли Python |
|---|---|
| Архив `full` из релиза | Нет |
| Архив `lite` из релиза | Только чтобы докачать скриншоты |
| `git clone` или «Download ZIP» | Да, чтобы скачать данные |

Подойдёт Python 3.6 или новее.

### Установка на Windows 10/11

Выбери любой способ. **После установки закрой терминал и открой заново**, иначе он не увидит Python.

**С сайта python.org.** Скачать установщик на https://www.python.org/downloads/, на первом экране отметить галочку **«Add python.exe to PATH»** и нажать «Install Now». Команды: `py` и `python`.

**Через winget** (встроен в Windows 10/11), в PowerShell или cmd:

```powershell
winget install -e --id Python.Python.3.13
```

Команда: `py`.

**Через Microsoft Store.** Найти в магазине «Python 3.13» и нажать «Получить». Команда: `python` (команды `py` нет).

**Через Scoop:**

```powershell
scoop install python
```

Команда: `python`.

**Через Chocolatey** (PowerShell от имени администратора):

```powershell
choco install python -y
```

Команда: `python`.

Проверить, что всё работает (одна из команд должна вывести версию):

```powershell
py --version
```

```powershell
python --version
```

### Установка на macOS и Linux

- **macOS:** установщик с https://www.python.org/downloads/ или `brew install python`. Команда: `python3`.
- **Ubuntu/Debian:** `sudo apt install python3`. **Fedora:** `sudo dnf install python3`. Команда: `python3`.

### Как открыть терминал в папке трекера

Команды нужно запускать **внутри папки трекера** (распакованной `eft-tracker` или папки репозитория).

- **Windows 11:** правый клик по пустому месту в папке → «Открыть в терминале».
- **Windows 10:** Shift + правый клик по пустому месту в папке → «Открыть окно PowerShell здесь».
- **Любая Windows:** в адресной строке Проводника набрать `powershell` или `cmd` и нажать Enter.
- **Вручную** (PowerShell и cmd), путь заменить на свой:

  ```powershell
  cd "C:\Users\Имя\Downloads\eft-tracker"
  ```

- **macOS:** правый клик по папке в Finder → «Службы» → «Новый терминал по адресу папки», или `cd ~/Downloads/eft-tracker`.

### Команды

Команды одинаковые для PowerShell и cmd, запускать их нужно из папки трекера (не из `scripts`). Колонка зависит от того, как установлен Python.

| Что сделать | Windows: python.org, winget | Windows: Store, Scoop, Chocolatey | macOS / Linux |
|---|---|---|---|
| Докачать скриншоты (lite) | `py scripts/get_screenshots.py` | `python scripts/get_screenshots.py` | `python3 scripts/get_screenshots.py` |
| Скачать скриншоты tarkov.help (≈425 МБ) | `py scripts/get_th_screenshots.py` | `python scripts/get_th_screenshots.py` | `python3 scripts/get_th_screenshots.py` |
| Скачать или обновить данные | `py scripts/update_quests.py` | `python scripts/update_quests.py` | `python3 scripts/update_quests.py` |
| Локальный сервер (по желанию), затем открыть http://localhost:5500 | `py -m http.server 5500` | `python -m http.server 5500` | `python3 -m http.server 5500` |
| Собрать архивы релиза | `py scripts/make_release.py` | `python scripts/make_release.py` | `python3 scripts/make_release.py` |

Если Python ставили с python.org с галочкой «Add python.exe to PATH», работают обе команды — и `py`, и `python`.

### Частые ошибки

- **`py : The term 'py' is not recognized…`** (PowerShell) или **`"py" не является внутренней или внешней командой…`** (cmd) — Python не установлен или поставлен без команды `py` (Store, Scoop, Chocolatey). Установи Python или используй `python`. После установки перезапусти терминал.
- **`python` открывает Microsoft Store или пишет `Python was not found`** — Python не установлен, это заглушка Windows. Установи Python любым способом выше. Заглушку можно отключить: «Параметры» → «Приложения» → «Дополнительные параметры приложений» → «Псевдонимы выполнения приложений».
- **`can't open file '…scripts/get_screenshots.py': No such file or directory`** — терминал открыт не в той папке. Перейди в папку трекера (см. выше) — в ней должны быть `index.html` и папка `scripts`.
- **`WinError 10060`, `timed out` или в конце «Не скачано картинок: … не отвечает assets.tarkov.dev»** — сервер картинок tarkov.dev не отвечает (у некоторых провайдеров он не открывается). Данные при этом собраны, трекер работает, вместо недостающих картинок — пустые места. Запусти скрипт ещё раз позже или через VPN: докачаются только недостающие. Либо возьми готовый архив со страницы релизов — там всё уже есть.
- **macOS: `CERTIFICATE_VERIFY_FAILED`** — запусти «Install Certificates.command» из папки «Программы» → «Python 3.x».
- **`scripts/get_screenshots.py`: «Не получилось скачать (404)»** — репозиторий стал приватным. Скачай архив `full` со страницы релизов.

## Что есть

- **Квесты** (`index.html`) — вкладки торговцев, поиск, сворачиваемые группы «Доступные», «Заблокированные» и «Выполненные».
- **Меню слева** — разделы «Квесты», «Сюжет», «Предметы», режим, фракция, тема и профиль (уровень, лояльность). Сворачивается до иконок, на телефоне выезжает по кнопке ☰.
- **Тёмная и светлая тема**, акцент цвета меняется вместе с режимом (PvP, PvE, сезон).
- **Режимы** PvP, PvE и Сезон (KORD BREACH) с отдельным прогрессом; фракции USEC/BEAR.
- **Блокировки** по уровню, лояльности торговцев, репутации Скупщика, сюжету («Тур» открывает торговцев, шаги «Борея» открывают квесты) и предыдущим квестам (цепочка Каппы и сезонная цепочка), включая требования «любой из».
- **Пометка «нет на tarkov-market»** у квестов, которых там нет: возможно, они устарели или убраны из игры.
- **Каппа** — квесты, которые хотя бы два источника из четырёх (tarkov-market, tarkov.help, игровые данные, вики) считают нужными для Каппы; сейчас их 114.
- **Сюжет** — 10 глав с обложками и шагами (`story.html`). Главу можно сбросить на её странице, весь сюжет — общей кнопкой «Сброс» на вкладке «Сюжет».
- **Страница квеста** (`quest.html`) — цели из игры с количеством, предметы, ключи, прохождение карточками, скриншоты с tarkov.help и ссылка на их гайд. Для квестов, где вики устарела или прохождения нет, — своё актуальное прохождение (170 квестов), текст вики свёрнут под ним.
- **Предметы** (`items.html`) — для квестов и убежища, отметка «найдено в рейде», счётчики.
- **Сброс** прогресса по разделам.
- **Копия прогресса в файл** — сохранить и загрузить все отметки (меню слева, блок «Прогресс»).

## Обновление данных

`scripts/update_quests.py` скачивает свежие данные tarkov.dev, недостающие иконки и фото квестов, добавляет данные из папки `sources/` и пересобирает файлы в `data/`. Папка `data/` и картинки `img/items/`, `img/quests/` в репозитории не хранятся — их создаёт скрипт, поэтому его нужно запустить перед первым запуском и повторять после патчей игры.

Прохождения, сюжет, сезонные квесты и скриншоты с вики (`sources/wiki_*.json`, `img/wiki/`) собираются вручную через браузер: вики закрыта проверкой Cloudflare. Так же вручную собраны связи с tarkov-market (`sources/tarkov_market.json`) адреса страниц и скриншотов tarkov.help (`sources/tarkov_help.json`) и обложки глав сюжета (`sources/story_covers.json`). Свои прохождения лежат в `sources/guides_own.json`.

Архивы для релиза собирает `scripts/make_release.py` в папку `release/` — после обновления данных.
